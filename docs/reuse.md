# Citation and reuse

This repository provides the supporting materials, source data and analysis code for our manuscript, **Global vegetation carbon stocks and PM2.5 interception decouple across future pollution pathways**, prepared for submission to *Nature Ecology & Evolution*.

Please cite the associated manuscript when reusing these materials. Author details, a DOI and a reuse licence have not yet been added; the submission status does not imply publication or acceptance.

Publicly accessible source datasets retain their original terms. Refer to the study methods and supporting information for data sources. Private processed assets and training inputs are not included in this package.

No additional permission to redistribute third-party inputs is implied by their use in the analysis. A code and data licence should be selected by the authors before release.
