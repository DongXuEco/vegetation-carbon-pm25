# Figure source data

Supporting data for **Global vegetation carbon stocks and PM2.5 interception decouple across future pollution pathways**.

| Figure | File or directory | Contents |
|---|---|---|
| Fig. 1 | [Fig. 1_latitudinal_source_data.xlsx](Fig.%201_latitudinal_source_data.xlsx) | Historical latitude profiles for carbon and PM2.5 adsorption |
| Fig. 2 | [Fig. 2_source_data.xls](Fig.%202_source_data.xls) | Biome and country/region summaries |
| Fig. 3 | [Fig. 3_source_data.xls](Fig.%203_source_data.xls) | Future time-series source data |
| Fig. 4 | [Fig. 4_mean_source_data.csv](Fig.%204_mean_source_data.csv) | Historical and SSP mean values for the inset bars |
| Fig. 5 | [Fig. 5_OLS_trend_source_data.csv](Fig.%205_OLS_trend_source_data.csv) | Historical and SSP OLS slopes for the inset bars; annual rates |
| Fig. S3 | [Fig. S3](Fig.%20S3/) | Carbon validation table and vector data |
| Figs. S12–S14 | [Fig. S12-14.xls](Fig.%20S12-14.xls) | Regional time series and attribution proportions |
| Extended Data Fig. 2 | [Extend Data Fig2 Cluster_map](Extend%20Data%20Fig2%20Cluster_map/) | Four-cluster map vector data |

These are the included source-data subsets, not all underlying raster inputs for every figure panel. Existing filenames and numerical values are retained.

For shapefiles, download the entire directory. The `.shp`, `.shx`, `.dbf` and `.prj` files are required to retain geometry, attributes and coordinate information; accompanying encoding and index files should also be kept.

See [units and classification codes](../docs/data_dictionary.md).

## Temporal attribution rasters

[Temporal_correlation_driver_rasters](Temporal_correlation_driver_rasters/) contains the historical and three SSP categorical rasters for Q–C temporal driver attribution, with their available companion files.

## Spatial attribution rasters

[Spatial_correlation_driver_rasters](Spatial_correlation_driver_rasters/) contains historical and three SSP four-class rasters for Q–C spatial driver attribution, with attribute tables and overviews.

## Adsorption temporal driver rasters

[Adsorption_temporal_driver_rasters](Adsorption_temporal_driver_rasters/) contains the historical and three SSP four-class rasters for drivers of Q trends, with available companion files. These classes describe contribution signs rather than Q–C correlation signs.
